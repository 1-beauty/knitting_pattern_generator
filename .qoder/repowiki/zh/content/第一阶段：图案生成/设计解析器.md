## 简介

设计解析器是针织图案生成系统的核心模块，负责将用户的自然语言描述转换为结构化的图案规格。该系统采用多阶段解析策略，通过LLM客户端与设计解析器的协作，实现了从自然语言到可执行图案设计的完整转换。

系统的主要特点包括：
- 支持多种输入格式的智能解析
- 多版本模式兼容的降级处理
- 结构化的视觉目标定义
- 完整的错误处理和恢复机制
- 高性能的JSON解析和规范化

### 解析算法实现

设计解析器的核心算法基于模式匹配和语义理解的结合：

```mermaid
flowchart TD
Start([开始解析]) --> ExtractJSON["提取JSON内容"]
ExtractJSON --> HasJSON{"找到有效JSON?"}
HasJSON --> |否| DefaultSpec["使用默认VisualSpec"]
HasJSON --> |是| ParseJSON["解析JSON数据"]
ParseJSON --> ParseSuccess{"解析成功?"}
ParseSuccess --> |否| FixJSON["修复JSON格式"]
FixJSON --> FixSuccess{"修复成功?"}
FixSuccess --> |否| DefaultSpec
FixSuccess --> |是| ParseFixed["解析修复后的JSON"]
ParseSuccess --> |是| SchemaDetect["检测schema版本"]
ParseFixed --> SchemaDetect
SchemaDetect --> VisualSchema{"视觉schema?"}
VisualSchema --> |是| ParseVisual["解析视觉schema"]
VisualSchema --> |否| MorphologyCompat["解析形态学兼容"]
MorphologyCompat --> MotifCompat["解析主题兼容"]
MotifCompat --> ElementsCompat["解析元素兼容"]
ParseVisual --> CreateSpec["创建VisualSpec"]
CreateSpec --> End([结束])
DefaultSpec --> End
```

## 性能考虑

设计解析器在性能方面采用了多项优化策略：

### 解析性能优化

1. **早期失败检测**：快速识别无效JSON格式
2. **缓存机制**：避免重复的正则表达式计算
3. **流式处理**：支持大文本的增量解析
4. **内存优化**：使用生成器和迭代器减少内存占用

### 错误处理优化

```mermaid
flowchart TD
ParseStart[解析开始] --> TryDirect[直接解析]
TryDirect --> DirectSuccess{直接成功?}
DirectSuccess --> |是| ReturnResult[返回结果]
DirectSuccess --> |否| TryFix[尝试修复]
TryFix --> FixSuccess{修复成功?}
FixSuccess --> |是| ReturnResult
FixSuccess --> |否| UseDefault[使用默认规格]
UseDefault --> ReturnDefault[返回默认结果]
ReturnResult --> ParseEnd[解析结束]
ReturnDefault --> ParseEnd
```

## 故障排除指南

### 常见解析错误

| 错误类型 | 症状 | 解决方案 |
|---------|------|----------|
| JSON格式错误 | 解析异常 | 使用内置修复器 |
| Schema不匹配 | 字段缺失 | 回退到兼容模式 |
| 数据类型错误 | 类型转换失败 | 使用规范化函数 |
| 缺失必需字段 | 验证失败 | 设置默认值 |

### 调试建议

1. **启用详细日志**：检查解析过程中的每一步
2. **验证输入格式**：确保JSON格式正确
3. **检查schema版本**：确认使用的schema兼容性
4. **测试边界条件**：验证极端输入的处理
